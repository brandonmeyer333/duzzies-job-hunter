# Duzzies Job Hunter Frontend

Static frontend for the Duzzies Job Hunter Supabase backend.

## Deploy
Publish this directory as a static site. No server-side secrets are required.

The frontend uses:
- Supabase Auth magic-link OTP
- `job-scan`
- `ai-job-matcher`
- `job-hunter-live` bootstrap/pending/review endpoints

External application submission remains behind user approval.
